Как установить

1. Подготовка версии

Установите в лаунчере NeoForge 1.21.1.

2. Распаковка

Распакуйте архив в любую папку.

Инфо для Windows: Игнорируйте папку __MACOSX внутри архива. Это технические файлы macOS, они не нужны для работы.

3. Перенос папок

Нажмите в лаунчере кнопку "Открыть папку" вашей версии игры. Перенесите туда из распакованного архива три папки:

• mods — файлы модов.
• config — файлы настроек.
• kubejs — скрипты сервера.

При необходимости согласитесь на замену файлов.

4. Вход

Запускайте игру и входите по IP. В чате используйте: /register [пароль] [пароль].
